## 关键结论
- 综合最优窗口: 4h（MAE 最低，Extreme MAE 最低，std 最小之一，表现稳定）。
- RMSE / R2 最优: 1h（RMSE 与 R2 最好，但 MAE 不占优）。
- 极端变化响应: Extreme RMSE 最低在 6h；4h 接近最优且更稳。
- 长窗口退化明显: 8h 在 MAE、RMSE、R2、稳定性上均明显退化，是当前最差区间。
- 建议: 后续主实验优先使用 4h；可保留 1h 作为短窗对照，6h 作为极端变化备选。

## 追加实验（随机未知站点，holdout_seed=3407）

### 实验步骤
1. 从 35 个站点中按 15% 抽样未知站点（holdout_seed=3407），固定用于整套实验。
2. 构建 split 产物（selected/test/holdout），训练集为除未知站点外的全部站点。
3. 依次设置窗口: 1,2,4,6,8,10,12 小时（t_len=2*hours）。
4. 训练模型（seed=3），评估采用滑动窗口（eval_stride=1）。
5. 使用 strict holdout 模式推断并生成 analysis_report 与 predictions_structured.csv。
6. 汇总每个窗口的总体指标与稳定性/极端变化指标，输出对比图。

- Holdout 站点: BC04, CD07, MSBJ, P10, P2
