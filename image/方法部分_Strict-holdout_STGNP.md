# 2. 方法

## 2.1 问题定义与总体框架

本文研究稀疏土壤水分监测网络中的严格站点级未见站点重建问题。给定一组已部署并可观测的土壤水分监测站点，模型需要在训练阶段仅利用观测站点的历史土壤水分序列和空间位置信息进行学习，并在推理阶段对训练过程中完全不可见的站点进行土壤水分重建。与普通缺失值补全或已知节点时间序列预测不同，本文任务的核心约束在于：严格留出的目标站点在训练阶段不提供土壤水分观测，不参与训练样本划分，也不作为节点出现在训练空间图中。模型只能在推理阶段根据目标站点的经纬度位置建立其与观测站点之间的空间连接，并输出其土壤水分重建结果。

设经过筛选后的土壤水分监测网络包含 $N$ 个站点，站点集合记为 $V=\{v_1,v_2,\ldots,v_N\}$。每个站点 $v_i$ 具有空间坐标 $s_i=(lon_i,lat_i)$，并按固定时间间隔记录 5 cm 深度土壤水分序列。本文将站点划分为训练阶段可观测的 context stations 集合 $C$ 和严格留出的 holdout target stations 集合 $T$。其中，$C \cap T=\varnothing$。训练阶段模型只能访问 $C$ 中站点的土壤水分序列和空间图结构；推理阶段，$T$ 中站点作为未见目标站点被动态加入，以完成土壤水分重建。

在长度为 $L$ 的历史时间窗口内，context stations 的土壤水分输入表示为 $Y_C \in \mathbb{R}^{|C|\times L\times 1}$。目标站点不提供真实土壤水分输入，仅提供空间查询特征 $X_T$，主要由站点经纬度或由经纬度计算得到的空间连接关系表示。模型目标是在给定 context 观测、目标查询和跨集合空间邻接的条件下，学习目标站点土壤水分的条件预测分布：

$$
p(Y_T \mid Y_C, X_T, A_{T,C}),
$$

其中 $Y_T \in \mathbb{R}^{|T|\times L\times 1}$ 为目标站点在同一时间窗口内的土壤水分序列，$A_{T,C}$ 表示从 context stations 到 holdout target stations 的跨集合空间邻接。当前实验仅使用土壤水分作为动态输入变量，因此动态观测维度为 $d_y=1$；若无额外气象或遥感协变量，则外生协变量维度可记为 $d_x=0$。

本文整体框架如图 1 所示。首先，原始 NAQU 土壤水分数据经过站点筛选、缺失值处理和归一化，形成统一的时序输入张量。随后，基于站点经纬度构建空间距离图，并在严格站点级 holdout 协议下生成 context-target 样本。最后，采用 strict-holdout Hierarchical STGNP 模型对未见站点进行概率重建。模型由确定性时空表示学习路径、随机潜变量聚合路径和观测解码器组成：确定性路径学习 context stations 与目标站点之间的多层时空表示；随机路径通过 Graph Bayesian Aggregation 聚合 context 信息并构造目标潜变量；观测解码器输出目标站点土壤水分的重建分布。

## 2.2 数据预处理与时空样本构建

### 2.2.1 站点筛选与缺失值处理

原始 NAQU 土壤水分站点数据包含多个候选监测站点，但不同站点之间的时间序列完整性存在明显差异。由于本文关注严格未见站点重建，如果目标站点在评价时间段内存在大量缺失值，则有效评价样本不足，误差统计容易产生不稳定偏差；同时，缺失严重的站点也会降低训练阶段可学习的时间动态质量。因此，本文首先统计各站点土壤水分序列中的缺失比例，并按缺失率对站点进行筛选。主实验保留缺失率低于 20% 的 35 个站点作为研究网络，以在空间覆盖范围和时间序列可用性之间取得平衡。

原始数据中，`-99.0` 表示缺失记录。对于站点 $v_i$ 在时间步 $t$ 的观测 $y_i^t$，本文构建二值缺失掩码 $m_i^t$：

$$
m_i^t=
\begin{cases}
1, & y_i^t \text{ 为缺失值},\\
0, & y_i^t \text{ 为有效观测值}.
\end{cases}
$$

缺失掩码用于区分真实观测与填补值。缺失位置不参与归一化统计量计算，也不参与最终误差评价。为了形成连续的模型输入序列，缺失位置首先由该站点在当前数据划分内的有效观测均值进行填补；若某站点在对应划分中不存在有效观测，则使用全局有效观测均值作为兜底。随后，仅基于非缺失观测计算均值 $\mu$ 和标准差 $\sigma$，并将土壤水分归一化为：

$$
\tilde{y}_i^t=\frac{y_i^t-\mu}{\sigma}.
$$

该处理方式保留了缺失信息，同时避免缺失标记或填补值直接影响数据统计分布。模型训练和推理过程中，缺失掩码与土壤水分输入共同使用，用于约束空间聚合和损失计算，使模型在存在观测缺口的情况下仍能稳定学习有效时空关系。

### 2.2.2 空间静态数据处理

空间静态信息用于描述不同站点之间的空间依赖关系。本文首先按照站点编号对经纬度表进行排序，确保站点元数据顺序与土壤水分时间序列矩阵列顺序一致。对于任意两个站点 $v_i$ 和 $v_j$，根据其经纬度坐标使用 Haversine 公式计算球面距离 $d_{ij}$。随后，通过 Gaussian kernel 将距离矩阵转换为空间邻接权重：

$$
A_{ij}=\exp\left[-\frac{1}{2}\left(\frac{d_{ij}}{\sigma_d}\right)^2\right],
$$

其中 $\sigma_d$ 为站点两两距离矩阵的标准差。该权重形式使距离较近的站点具有更强连接，距离较远的站点仍保留较弱但连续衰减的空间影响。与硬阈值邻接相比，Gaussian kernel 能够更平滑地表达高原区域稀疏站点之间的空间相关性。

在 strict holdout 场景下，空间图构建需要区分训练阶段和推理阶段。训练阶段，空间图只由训练可见站点构成，holdout stations 不作为图节点参与任何邻接传播。推理阶段，holdout station 根据其经纬度被动态追加为目标节点，并重新计算其与 context stations 之间的距离加权连接。该过程仅使用目标站点的空间位置，不使用其土壤水分历史观测，因此不会破坏严格未见站点约束。

### 2.2.3 时间动态数据处理

时间动态信息用于描述土壤水分在短期历史窗口内的变化状态。经过缺失值处理和归一化后，所有站点的土壤水分序列被组织为三维张量：

$$
Y \in \mathbb{R}^{N\times T\times 1},
$$

其中 $N$ 为站点数量，$T$ 为时间步数量，最后一维表示 5 cm 土壤水分这一单变量观测。本文采用固定长度滑动窗口构建模型样本。设输入窗口长度为 $L$，则站点 $v_i$ 在样本起点 $t$ 的时间窗口表示为：

$$
Y_{i,t:t+L-1}=
\{\tilde{y}_i^t,\tilde{y}_i^{t+1},\ldots,\tilde{y}_i^{t+L-1}\}.
$$

由于原始土壤水分数据的采样间隔为 30 min，长度为 $L$ 的输入窗口对应 $L/2$ 小时的历史观测。主实验可根据实验设置选择 $L$ 的取值；不同窗口长度对重建效果的影响可在实验部分进一步分析。方法部分仅将滑动窗口视为统一的时序样本构建方式，不将其作为单独模型模块处理。

滑动窗口构建后，每个样本同时包含 context stations 的土壤水分窗口、目标站点监督窗口、对应缺失掩码、时间戳信息以及跨集合邻接矩阵。训练时，目标站点窗口仅用于构造监督信号和变分后验；推理时，模型不接收 holdout station 的土壤水分输入，只根据 context stations 的历史窗口和空间邻接输出目标站点重建结果。

### 2.2.4 Strict holdout 下的 context-target 样本组织

严格站点级 holdout 在数据划分阶段完成。给定 holdout stations 集合 $T$，本文首先从训练站点集合、土壤水分序列矩阵和训练空间图中同时移除这些站点，使模型训练阶段只能接触剩余观测站点的时间序列及其空间关系。换言之，holdout stations 既不作为训练 context，也不作为训练 target，更不参与训练图中的邻接传播。

训练阶段，为了使模型学习从部分观测站点到目标站点的条件映射，可在训练可见站点内部构造临时的 context-target 样本。对于训练站点集合 $S_{\text{train}}$，每个训练样本将其中一部分站点作为 context set $C_{\text{train}}$，另一部分站点作为 target set $T_{\text{train}}$，并基于当前样本的站点划分提取跨集合邻接：

$$
A^{(1)}_{T,C}=A[T,C].
$$

为提供更宽范围的空间上下文，本文进一步构建二阶跨集合邻接：

$$
A^{(2)}_{T,C}=A^2[T,C].
$$

最终图输入可表示为 $[A^{(1)}_{T,C},A^{(2)}_{T,C}]$ 的拼接张量，其形状为 $2\times |T|\times |C|$。其中，一阶邻接刻画目标站点与观测站点之间的直接距离衰减关系，二阶邻接为模型提供通过中间站点传播的间接空间关系。

测试或推理阶段，context set 由训练阶段可见站点构成，target set 则为严格留出的 holdout stations。此时跨集合邻接为 $A_{T_{\text{holdout}},C_{\text{train}}}$。目标站点真实土壤水分序列只在模型完成预测后用于评价，不进入模型输入。该样本组织方式保证了模型评价的是严格意义上的未见站点外推能力，而不是已知节点上的缺失补全能力。

## 2.3 Strict-holdout Hierarchical STGNP 模型

### 2.3.1 模型总体架构

本文采用 Hierarchical Spatio-Temporal Graph Neural Process 作为土壤水分重建模型，并将其适配到严格站点级 holdout 场景。模型结构如图 2 所示。整体上，模型包含三个核心部分：确定性时空表示学习路径、随机潜变量聚合路径和观测解码器。确定性路径通过跨集合图卷积和扩张因果卷积学习 context stations 与 holdout target stations 的多层时空表示；随机路径通过 Graph Bayesian Aggregation 在每一层构造目标站点潜变量分布；观测解码器根据多层潜变量输出目标站点土壤水分的概率重建结果。

![Strict-holdout Hierarchical STGNP 架构图](image/stgnp_architecture.png)

**图 2.** Strict-holdout Hierarchical STGNP 架构。蓝色变量表示 context stations 相关信息，橙色变量表示 holdout target station 相关信息。确定性路径学习多层时空表示，随机路径通过 GBA 生成目标潜变量，最终输出未见站点土壤水分重建分布。

对于 context stations，模型输入包括其土壤水分观测窗口 $Y_C$ 以及可选的空间或时间查询特征 $X_C$。对于 holdout target stations，模型不能使用目标站点真实土壤水分 $Y_T$ 作为输入，因此目标节点以空间查询特征 $X_T$ 和目标查询嵌入 $e$ 进行初始化。这里的 $e$ 可理解为目标节点初始表示，用于标识“该节点为待重建的未见站点”。该设计避免了将零值、均值或插值结果误作为目标站点真实观测输入，从而更符合 strict holdout 的设定。

在第 $l$ 层中，context stations 的确定性表示记为 $H_C^l$，holdout target stations 的确定性表示记为 $V_T^l$。二者共同输入到随机路径，通过 GBA 得到目标潜变量 $Z_T^l$。多层潜变量 $\{Z_T^l\}_{l=1}^{L_s}$ 共同参与最终解码，其中 $L_s$ 表示 STGNP 的层数。模型输出为目标站点土壤水分的条件分布：

$$
p(Y_T\mid X_T,Y_C,A_{T,C}).
$$

与普通时空图神经网络相比，STGNP 的关键差异在于其概率建模能力。它不只学习一个确定性映射 $\hat{Y}_T=f(Y_C,A_{T,C})$，而是通过潜变量建模目标站点重建中的不确定性。因此，模型既能给出预测均值，也能保留预测方差或置信区间，为稀疏站点条件下的重建结果提供不确定性刻画。

### 2.3.2 确定性时空表示学习

确定性时空表示学习模块用于从 context stations 的土壤水分历史窗口中提取可迁移到 holdout target stations 的时空上下文。该模块对应图 2 中的 STRL 层。每一层 STRL 主要由 Cross-Set Graph Convolutional Network（CSGCN）和 Dilated Causal Convolution（DCConv）组成，分别负责空间依赖建模和时间动态建模。

首先，context stations 的土壤水分观测窗口 $Y_C$ 通过输入嵌入层映射到隐藏空间：

$$
H_C^0=\phi_y(Y_C).
$$

对于 holdout target stations，由于其真实土壤水分序列在推理阶段不可用，模型使用目标查询嵌入初始化其隐藏表示：

$$
V_T^0=e.
$$

如果目标站点包含经纬度或其他静态查询特征，则可将这些特征与 $e$ 共同映射为目标初始表示。该初始化方式的作用不是提供目标站点观测值，而是为模型提供一个可被后续空间聚合和随机路径更新的目标节点表示。

CSGCN 用于建模 context stations 到 target stations 的跨集合空间传播。与普通 GCN 在完整节点集合上进行全图传播不同，CSGCN 强调 context set 与 target set 之间的信息交互。对于目标站点 $m\in T$，模型根据跨集合邻接权重从 context station $n\in C$ 聚合信息。该过程可简化表示为：

$$
V_m^l=
f_{\text{CSGCN}}\left(
V_m^{l-1},
\{H_n^{l-1},A_{m,n}\}_{n\in C}
\right),
$$

其中 $A_{m,n}$ 为目标站点 $m$ 与 context station $n$ 之间的空间邻接权重，$f_{\text{CSGCN}}(\cdot)$ 为跨集合图聚合映射。若输入包含一阶和二阶邻接，则模型可以同时利用直接空间关系与间接空间上下文。对于 strict holdout 任务而言，CSGCN 的意义在于：holdout station 不需要出现在训练图中，但在推理阶段仍可通过其经纬度与 context stations 建立跨集合连接，从而接收周围观测站点的信息。

在空间聚合之后，DCConv 用于提取土壤水分时间窗口中的动态特征。因果卷积保证当前时间步的表示只依赖当前及过去时间步，避免未来信息泄露；扩张卷积通过增大卷积采样间隔扩展时间感受野，使上层能够捕捉更长范围的时序变化。对站点 $i$ 在时间步 $t$ 的隐藏表示，扩张因果卷积可写为：

$$
h_{i,t}^{l}
=
\sum_{s=0}^{k-1}
K^l(s)\odot H_i^{l-1}(t-\eta s),
$$

其中 $k$ 为卷积核大小，$\eta$ 为扩张率，$K^l$ 为第 $l$ 层卷积核，$\odot$ 表示逐元素乘积。通过堆叠多层 DCConv，模型可以在不使用循环结构的情况下学习短期和中期土壤水分变化规律，并降低长序列递归转移带来的信息衰减问题。

经过多层 STRL 后，模型得到 context stations 和 holdout target stations 的层级确定性表示：

$$
\{H_C^1,H_C^2,\ldots,H_C^{L_s}\},
\qquad
\{V_T^1,V_T^2,\ldots,V_T^{L_s}\}.
$$

低层表示更侧重局部时间变化和近邻空间关系，高层表示包含更大时间感受野和更抽象的空间上下文。这些多尺度表示为后续随机潜变量聚合提供了确定性基础。

### 2.3.3 Graph Bayesian Aggregation 与随机潜变量建模

严格未见站点重建具有天然不确定性。一方面，holdout station 在训练阶段完全不可见，其土壤水分变化只能由周围 context stations 间接推断；另一方面，不同 context stations 与目标站点之间的空间距离、观测缺失程度和局部环境差异并不相同，其信息可靠性也不同。因此，本文采用 Graph Bayesian Aggregation（GBA）在每一层为目标站点构造随机潜变量分布，以表达重建过程中的不确定性。

对于第 $l$ 层目标站点 $m$，模型引入潜变量 $Z_m^l$，并将其建模为高斯分布：

$$
Z_m^l \sim \mathcal{N}(\mu_m^l,(\sigma_m^l)^2).
$$

GBA 的基本思想是：目标站点首先根据自身确定性表示 $V_m^l$ 和上层潜变量状态形成一个先验分布；随后，每个 context station 根据其表示 $H_n^l$ 生成一个带不确定性的 latent observation；最后，模型根据空间邻接权重和 context observation 的不确定性对目标潜变量进行贝叶斯聚合。

具体而言，目标潜变量的先验可表示为：

$$
p(Z_m^l)=
\mathcal{N}\left(
Z_m^l \mid \mu_{t,m}^l,(\sigma_{t,m}^l)^2
\right),
$$

其中 $\mu_{t,m}^l$ 和 $\sigma_{t,m}^l$ 由目标站点表示 $V_m^l$ 以及上层潜变量状态通过神经网络估计得到。对于 context station $n$，模型根据其确定性表示 $H_n^l$ 估计 latent observation：

$$
R_n^l,\sigma_{c,n}^l = \text{Enc}_R^l(H_n^l),
$$

其中 $R_n^l$ 表示 context station 对目标潜变量提供的信息，$\sigma_{c,n}^l$ 表示该信息的不确定性。随后，GBA 结合跨集合邻接权重 $\tilde{A}_{m,n}$ 对目标潜变量分布进行更新。其聚合形式可概括为：

$$
\bar{\sigma}_{m}^{2}
=
\left[
\frac{1}{\sigma_{t,m}^{2}}
+
\sum_{n\in C}
\frac{\tilde{A}_{m,n}^{2}}{\sigma_{c,n}^{2}}
\right]^{-1},
$$

$$
\bar{\mu}_{m}
=
\bar{\sigma}_{m}^{2}
\left[
\frac{\mu_{t,m}}{\sigma_{t,m}^{2}}
+
\sum_{n\in C}
\frac{\tilde{A}_{m,n}^{2}R_n}{\sigma_{c,n}^{2}}
\right].
$$

其中 $\bar{\mu}_m$ 和 $\bar{\sigma}_m^2$ 为聚合后的目标潜变量分布参数，$\tilde{A}_{m,n}$ 为经过归一化或缺失掩码调节后的目标—context 邻接权重。该形式体现了两类权重作用：其一，空间邻接权重较大的 context station 对目标站点贡献更强；其二，不确定性较大的 context observation 贡献会被自动减弱。因此，距离目标站点较近且观测表示更可靠的 context station 会对目标潜变量产生更大影响，而远距离或高不确定性的站点贡献较小。

GBA 使模型能够在 strict holdout 条件下更合理地聚合观测站点信息。对于未见站点，模型无法依赖其历史观测，只能通过空间邻接从 context stations 获取线索。若简单使用平均聚合或注意力聚合，模型难以显式区分站点距离和观测不确定性；而 GBA 通过概率形式将二者统一到潜变量更新中，从而提高重建的稳健性和可解释性。

训练阶段，模型同时构造条件先验分支和近似后验分支。条件先验分支仅使用 context stations 和目标查询表示，近似 $p(Z_T\mid Y_C,A_{T,C})$；近似后验分支在训练时额外使用目标站点监督值，近似 $q(Z_T\mid Y_C,Y_T,A_{T,C})$。推理阶段没有目标站点真实土壤水分，因此只使用由 context stations 诱导的条件先验进行预测。

### 2.3.4 观测解码与优化目标

完成多层 GBA 后，模型获得目标站点在不同层级上的随机潜变量：

$$
Z_T = \{Z_T^1,Z_T^2,\ldots,Z_T^{L_s}\}.
$$

这些潜变量在通道维度上拼接，并输入观测解码器。观测解码器由多层 $1\times1$ 卷积或等价的逐时间步映射构成，用于输出目标站点土壤水分的高斯预测分布：

$$
p(Y_T\mid X_T,Y_C,A_{T,C})
=
\mathcal{N}(\mu_T,\sigma_T^2).
$$

其中 $\mu_T$ 表示预测均值，作为最终土壤水分重建值；$\sigma_T^2$ 表示预测方差，用于刻画模型不确定性。为保证尺度参数为正，解码器输出的方差或标准差通常经过 softplus 等非负变换。

由于潜变量后验无法直接解析求解，模型采用变分近似进行训练。训练目标由有效目标观测上的负对数似然项和后验—先验 KL 散度项组成：

$$
\mathcal{L}
=
-\mathbb{E}_{q(Z_T)}
\left[
\log p(Y_T\mid Z_T,X_T)
\right]
+
\beta
D_{\mathrm{KL}}
\left(
q(Z_T\mid Y_C,Y_T,A_{T,C})
\Vert
p(Z_T\mid Y_C,A_{T,C})
\right),
$$

其中 $\beta$ 为 KL 权重。第一项鼓励模型生成接近真实目标序列的土壤水分重建结果；第二项约束训练阶段近似后验与推理阶段可用的条件先验保持一致，从而保证模型在没有目标观测输入时仍能稳定推断。

在损失计算中，目标站点的缺失掩码用于过滤无效观测。仅当目标值为有效土壤水分记录时，该时间步才参与似然项和误差统计。训练时，潜变量采样可通过 reparameterization trick 实现端到端优化；推理时，为获得稳定重建结果，通常使用条件先验分布的均值或预测分布均值作为最终输出。

## 2.4 未见站点推理

### 2.4.1 Holdout stations 的动态加入

推理阶段，模型进入严格未见站点重建模式。首先，数据集读取训练阶段可见的观测站点作为 context stations，并加载其对应测试时间段内的土壤水分历史窗口和缺失掩码。随后，对于每个 holdout station，数据集从完整站点元数据中读取其经纬度坐标，将其作为目标节点动态追加到当前样本中。

需要强调的是，动态加入只涉及空间位置和目标查询表示，不包含目标站点的土壤水分历史输入。换言之，holdout station 的真实土壤水分序列不会作为模型输入参与推理，而只在重建完成后用于计算评价指标。该设计保证了推理过程与训练阶段的 strict holdout 假设一致。

### 2.4.2 Context-to-holdout adjacency 构建

目标站点加入后，模型根据 holdout station 与 context stations 的经纬度重新计算空间距离，并通过 Gaussian kernel 得到 context-to-holdout adjacency：

$$
A_{T_{\text{holdout}},C_{\text{train}}}
=
\exp
\left[
-\frac{1}{2}
\left(
\frac{d(T_{\text{holdout}},C_{\text{train}})}{\sigma_d}
\right)^2
\right].
$$

若模型使用多阶邻接，则进一步计算对应的二阶跨集合邻接，并将一阶与二阶邻接共同输入 CSGCN 和 GBA。该邻接矩阵是推理阶段目标站点接收 context 信息的唯一空间通道。由于目标站点在训练图中不存在，模型不能依赖其训练期节点表示；相反，它通过空间查询和 context-to-holdout adjacency 在推理阶段临时构造目标表示。

### 2.4.3 土壤水分重建输出

给定 context stations 的土壤水分窗口 $Y_C$、目标站点空间查询 $X_T$ 以及跨集合邻接 $A_{T,C}$，模型首先通过确定性路径获得多层 $H_C^l$ 和 $V_T^l$，随后通过 GBA 得到目标潜变量 $Z_T^l$，最后由观测解码器输出目标站点的土壤水分预测分布：

$$
p(Y_T\mid X_T,Y_C,A_{T,C})
=
\mathcal{N}(\mu_T,\sigma_T^2).
$$

本文将预测均值 $\mu_T$ 作为 holdout station 的土壤水分重建结果。预测方差 $\sigma_T^2$ 可作为模型不确定性输出，用于辅助判断不同目标站点或不同时间段的重建可靠性。最终评价仅在 holdout stations 的非缺失真实观测上进行，以确保误差统计反映有效土壤水分记录上的重建性能。

通过上述推理流程，模型能够在不访问目标站点训练期土壤水分序列的条件下，仅利用已观测站点的时空上下文和目标站点空间位置完成未见站点重建。这一过程体现了本文方法与普通已知节点缺失补全方法的本质区别：目标站点不是训练图中的已见节点，而是在推理阶段才被动态查询的严格未见站点。
